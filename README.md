# data-mining

📊 Data Mining Repository

Repository ini berisi Implementasi dan praktik Data Mining.
Setiap file memiliki beberapa implementasi kode yang mencakup berbagai tahapan dalam proses data mining.

## 📄 Deskripsi File

### 🔹 pengukuran-kedekatan-dan-similaritas-data.ipynb

Notebook ini berisi pembahasan dan implementasi metode untuk mengukur tingkat kedekatan atau kemiripan antar data, yang menjadi dasar dalam berbagai teknik data mining seperti clustering dan klasifikasi.

---

### 🔹 implementasi-distance-measure.ipynb

Berisi implementasi berbagai metode distance measure (pengukuran jarak) seperti Euclidean, Manhattan, atau metode lainnya untuk menghitung jarak antar data.

---

### 🔹 klasifikasi-decision-tree-dan-rule-based-classifier.ipynb

Notebook ini mengimplementasikan metode klasifikasi menggunakan:

* Decision Tree
* Rule-Based Classifier

Digunakan untuk memahami proses pengambilan keputusan berbasis aturan dari data.

---

### 🔹 klasifikasi-probabilistic-dan-instancy-based.ipynb

Berisi implementasi metode klasifikasi berbasis:

* Probabilistic (misalnya Naive Bayes)
* Instance-Based (misalnya K-Nearest Neighbors / KNN)

Digunakan untuk membandingkan pendekatan probabilistik dan berbasis instance.

---

### 🔹 klasifikasi-ensemble-method.ipynb

Notebook ini membahas dan mengimplementasikan metode ensemble, yaitu teknik yang menggabungkan beberapa model untuk meningkatkan performa klasifikasi, seperti:

* Bagging
* Boosting
* Random Forest
